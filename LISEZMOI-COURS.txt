Cours de langues Éclozia — anglais, espagnol, allemand (kdp-serveur)
=====================================================================

ADRESSES
  https://parleranglais.geteclozia.com    (déjà en ligne)
  https://parlerespagnol.geteclozia.com   (nouveau)
  https://parlerallemand.geteclozia.com   (nouveau)

1. FICHIERS À METTRE SUR GITHUB (aucun secret dedans)
  cours.js        gère les 3 cours, le référencement, robots.txt et sitemap.xml
  server.js       2 lignes ajoutées (/espagnol et /allemand)
  cours.html      page anglaise + liens vers l'espagnol et l'allemand
  langue.html     page commune des cours d'espagnol et d'allemand
  og-anglais.png, og-espagnol.png, og-allemand.png   images de partage
  LISEZMOI-COURS.txt

2. FICHIERS SECRETS (JAMAIS sur GitHub : c'est le contenu payant)
  Render > kdp-serveur > Environment > Secret Files > Add Secret File
    espagnol-content.json   (coller le contenu du fichier)
    allemand-content.json   (coller le contenu du fichier)
  cours-content.json (anglais) reste tel quel.

3. DEUX PRODUITS GUMROAD
  Créez « Parler espagnol » et « Parler allemand », avec l'option
  « Generate a unique license key per sale » cochée, comme pour l'anglais.
  Notez l'ID de produit et l'adresse de chaque page de vente.

4. VARIABLES D'ENVIRONNEMENT RENDER (Environment > Add Environment Variable)
  GUMROAD_PRODUCT_ESPAGNOL = ID du produit espagnol
  ESPAGNOL_GUMROAD_URL     = https://eclozia.gumroad.com/l/... (adresse complète)
  ESPAGNOL_PRIX            = 12 $
  ESPAGNOL_HOST            = parlerespagnol.geteclozia.com
  GUMROAD_PRODUCT_ALLEMAND = ID du produit allemand
  ALLEMAND_GUMROAD_URL     = https://eclozia.gumroad.com/l/...
  ALLEMAND_PRIX            = 12 $
  ALLEMAND_HOST            = parlerallemand.geteclozia.com
  NE PAS ajouter ces ID à GUMROAD_PRODUCT_IDS.

5. SOUS-DOMAINES
  Spaceship > DNS de geteclozia.com > 2 enregistrements CNAME :
    parlerespagnol  →  kdp-serveur.onrender.com
    parlerallemand  →  kdp-serveur.onrender.com
  Render > kdp-serveur > Settings > Custom Domains > Add :
    parlerespagnol.geteclozia.com  puis  parlerallemand.geteclozia.com
  Attendre la coche verte « Certificate issued ».

6. DÉPLOIEMENT
  Manual Deploy > Deploy latest commit.
  Vérifications :
    https://parlerespagnol.geteclozia.com/espagnol/preview → {"ok":true,...}
    https://parlerallemand.geteclozia.com/allemand/preview → {"ok":true,...}
  « contenu du cours n'est pas encore installé » = fichier secret absent ou mal nommé.

7. ADMINISTRATION DES APPAREILS
  https://parleranglais.geteclozia.com/cours/admin : choisissez le cours dans
  la liste, collez la clé du client, puis « Réinitialiser les appareils ».

8. RÉFÉRENCEMENT (Google et Bing)
  Ce qui est déjà fait par le serveur, sur chaque sous-domaine :
    titre et description optimisés, lien canonique, image de partage (og.png),
    données structurées « Course » (prix, langue, en ligne), robots.txt, sitemap.xml.
  À faire une seule fois :
    a) Google Search Console (search.google.com/search-console)
       Ajouter une propriété > « Domaine » > geteclozia.com
       Google donne un enregistrement TXT : ajoutez-le dans Spaceship (DNS, type TXT,
       hôte @). Cliquez « Valider ». Cette seule validation couvre tous les sous-domaines.
       Puis, pour chaque cours : Sitemaps > ajoutez
         https://parleranglais.geteclozia.com/sitemap.xml
         https://parlerespagnol.geteclozia.com/sitemap.xml
         https://parlerallemand.geteclozia.com/sitemap.xml
       Et « Inspection de l'URL » > collez l'adresse du cours > « Demander l'indexation ».
    b) Bing Webmaster Tools (bing.com/webmasters) : « Importer depuis Google Search
       Console » (2 clics). Bing alimente aussi DuckDuckGo et Yahoo.
    c) Liens entrants (ce qui fait le plus monter un site) :
       - lien dans la description de chaque vidéo YouTube, TikTok et Facebook ;
       - lien sur geteclozia.com (page d'accueil ou menu « Cours ») ;
       - lien dans le livre (page bonus), sur les fiches Gumroad et Etsy ;
       - profils : Pinterest, LinkedIn, groupes Facebook de francophones expatriés.
  Délai normal : 1 à 4 semaines avant d'apparaître dans Google.
  Tester l'aperçu de partage : https://www.opengraph.xyz (collez l'adresse).
